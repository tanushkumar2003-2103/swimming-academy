SWIMMING ACADEMY - MULTI-PAGE PREMIUM WEBSITE
========================================================================

PROJECT OVERVIEW:
A complete, modern, premium-quality, professional, visually attractive, 
and fully responsive multi-page website developed for SWIMMING ACADEMY.

TECHNOLOGY STACK:
- HTML5 (Semantic elements, accessibility landmarks, clean markup)
- CSS3 (Aquatic color system, responsive grid/flexbox, smooth transitions)
- Vanilla JavaScript (Sticky navigation, mobile drawer, form validation, 
  schedule filters, pricing interaction, FAQ accordion, gallery lightbox)
- Strictly NO external frameworks, libraries, APIs, or databases.

BRANDING:
- Exact Category Name: SWIMMING ACADEMY
- No fictional names or external branding.
- Text-based logo: SWIMMING ACADEMY with aquatic glyph.

8 COMPLETE HTML PAGES:
1. index.html                 - Homepage with Hero, Intro, Programs, Highlights, CTA
2. about.html                 - Training Philosophy, Mission & Vision, Values, Facility
3. programs.html              - 6 Detailed Program Tracks, Objectives & Water Safety Notice
4. kids-swimming.html         - Kids & Teen Batches, Safety Warnings, Parent Guidelines, FAQs
5. adult-swimming.html        - Adult Beginner, Fitness, Stroke Refinement, Health Notice
6. coaches-gallery.html       - Demonstration Instructor Profiles, Approach & Lightbox Gallery
7. schedule-membership.html   - Filterable Schedule & INR (₹) Pricing Plans & Comparisons
8. contact.html               - Trial Class Registration Form, Enquiry Form & Map Placeholder

IMAGE PLACEHOLDER COMPLIANCE:
Strictly limited to the 8 approved CSS placeholders:
1. swimming-hero
2. swimming-training
3. swimming-instructor
4. swimming-kids
5. swimming-adults
6. swimming-pool
7. swimming-competition
8. swimming-group

Clear HTML comments are included across all pages indicating where images
generated through Google Flow can be inserted in the future.

HOW TO RUN:
Simply double-click or open `index.html` in any modern web browser.
No build tools, package managers, or local servers are required.
